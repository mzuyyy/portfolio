# Portfolio design

## Direction
Editorial portfolio for a Vietnamese creative developer. Warm paper canvas, oversized typography, terracotta accent, restrained rules and asymmetric project compositions. Content is clearly identified as demo content until personalized.

## Tokens
Canvas #f5f3ee; ink #262620; muted #68685f; rule #d9d7cf; accent #a74126; white #ffffff. Typography: Arial sans serif with Georgia italic for editorial emphasis. Content maximum 1280px; page gutter clamp(24px, 5vw, 80px). Spacing scale 8/16/24/32/48/64/96. Borders 1px; card radius 3px; buttons 4px. Motion 180ms ease; respect reduced motion.

## Components and layout
Header with wordmark and anchor navigation. Split hero with typographic heading and code-native orbital graphic. Project grid with shared project card, filter chips and native detail dialog. About section and high-contrast contact footer. Mobile collapses columns with accessible menu toggle.

## Accessibility and debt
Semantic landmarks, skip link, focus-visible outlines, native dialog, labeled controls. No external font or image dependency. Light theme only. Project details and contact are explicitly demo content. Browser rendering requires verification on the host environment.
