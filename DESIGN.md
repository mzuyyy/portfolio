# Portfolio design — AI Engineer

## Direction
Apply installed anthropics/skills frontend-design. Audience: AI teams, research collaborators and recruiters. The distinctive element is a large motion-study figure: spatial joints and temporal skeleton frames evoke Duy's ST-GCN work. Avoid generic robot mascots, terminal chrome, sequential section numbers and simulated dashboards. Quiet editorial hierarchy around this single focal visual.

## Tokens

Dark: canvas #171e19, surface #202a22, ink #ecf0e7, muted #adb9a9, accent #bdd3a8, line #3a483b, soft #2b382c. Gutter 24–64px; content width 1240px; spacing 8/16/24/32/48/64/96. Button radius 8px, illustration radius 16px. Light theme is initial default, saved user selection takes precedence.

## Layout
Hero: name and role, large left-aligned Vietnamese statement, brief introduction, two actions; figure at right. Bottom line lists research fields. Projects: asymmetrical featured UEBA row then two-column project grid. Experience: date column and clear narrative. About: two columns with compact toolbox. Contact: large quiet invitation with email actions. Mobile: single column, illustration retained, collapsible navigation.

## Behavior and accessibility
Preserve all project links, full details, light/dark theme, native dialog, filters and clipboard feedback. Focus-visible, touch targets minimum 44px, reduced-motion support. No fake metrics, invented experience, source commentary or external dependencies at runtime. Self-hosted font license in assets/fonts/OFL.txt. GitHub Pages remains deployment target.
