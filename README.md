# Portfolio

Portfolio tiếng Việt bằng HTML/CSS/JavaScript thuần. Mở `index.html` trong trình duyệt, không cần cài dependency.

Thay tên, giới thiệu, kỹ năng và email mẫu `hello@example.com` trong `index.html`. Sửa chi tiết dự án trong `script.js`. Ba dự án hiện tại là concept minh họa, chưa phải dự án cá nhân thật.

Có lọc dự án, dialog chi tiết hỗ trợ Escape, menu mobile, sao chép email và hỗ trợ reduced motion. Hình minh họa dựng bằng CSS, không cần dịch vụ ảnh hay font ngoài.
